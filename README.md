# English Life · 生活英语

给零基础成年人的生活英语学习网页应用（单词、听力、跟读、按记忆规律复习）。

> 当前是 **Beta 内测版**（V4：约 1500 个词、54 段对话、5 集生活剧情、合成语音），不代表正式产品验收通过；内容经程序检查和 AI 初审，没有经过人工逐条审核。

- 在线使用：https://sanaung199635-jpg.github.io/english-life/
- 这个仓库只包含**打包好的网站文件**（由源码版本 `8035757` 构建，2026-11-04）。源代码不在这里。
- 学习内容（单词、句子、对话、题目）均为原创。发音是开源模型 Kokoro 生成的美式合成语音（不是真人录音），加载失败时使用设备自带的系统语音。
- 学习记录只保存在你自己的设备上，不上传任何服务器。
